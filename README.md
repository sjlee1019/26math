# 26math · 발견하는 수학 실험실

## 수업 철학
교사가 지식을 주입하기보다 학생들이 직접 다양한 활동으로 수학적 개념을 발견하고 아이디어를 발전시키는 역동적인 수업을 지향합니다. 앞으로의 개발에서도 예상 → 조작 → 관찰 → 설명 → 공유의 흐름을 우선합니다.

## 실행
외부 의존성 없이 동작하는 정적 웹 앱입니다.

```sh
cd /workspace/26math
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저로 실행한 서버에 접속합니다. 닮음비 조절로 길이와 넓이의 관계를 탐구하고, 네 직각삼각형을 활용한 피타고라스 정리의 넓이 증명을 확인합니다. 발견 노트는 브라우저 로컬 저장소에 저장되며 다른 학생과 자동 공유되지는 않습니다.
